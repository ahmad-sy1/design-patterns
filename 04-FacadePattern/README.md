# Facade Pattern

Deze map bevat de console-applicaties voor het Facade Pattern:

| Map | Inhoud |
|-----|--------|
| [Deelopdrachten/](Deelopdrachten/README.md) | Startopdracht: GameApp, een game die opstart via losse subsystemen (graphics, audio, opslag, netwerk en engine). |
| Hoofdopdracht/ | Officiële Teams-opdracht: HomeTheaterFacade. Volgt later, de startcode (FacadePattern.zip) ontbreekt nog. |

In `Design-Patterns.sln` staat Deelopdrachten als `FacadePattern.Deelopdrachten`.
